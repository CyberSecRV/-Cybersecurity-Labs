# Evidence

This directory contains selected evidence collected during the
controlled security assessment.

## Evidence Handling

Evidence is reviewed before publication.

The following information must not be included:

- Passwords
- API keys
- Private keys
- Tokens
- Personal information
- Unrelated system information
- Third-party data
- Sensitive network information

## Evidence Categories

Evidence may include:

- Service identification
- Vulnerability validation
- Session establishment
- Privilege assessment
- Security impact
- Remediation verification

Only evidence relevant to the assessment will be published.
